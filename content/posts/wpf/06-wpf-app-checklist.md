# WPF 앱 실무 체크리스트

> 요약: 아키텍처, 성능, 배포, 예외 처리까지 WPF 앱 릴리스 전에 확인할 실무 체크리스트를 정리한다.

---

## 1. 아키텍처

- [ ] MVVM 경계 유지 (ViewModel에 UI API 직접 호출 최소화)
- [ ] Command 기반 액션
- [ ] 공통 서비스(대화상자/파일/설정) 추상화
- [ ] 폴더 구조(Views/ViewModels/Services) 일관성

---

## 2. 성능

- [ ] 큰 리스트는 virtualization 확인
- [ ] 무거운 바인딩/컨버터 남용 점검
- [ ] 이미지 리소스 크기 최적화
- [ ] UI 스레드 블로킹 작업은 async/Task로 분리

---

## 3. 안정성

- [ ] 전역 예외 로깅(App.xaml.cs)
- [ ] 저장/로드 실패 메시지 처리
- [ ] 설정 파일 마이그레이션 전략

---

## 4. 배포

- [ ] 대상 .NET 런타임 확인
- [ ] MSIX/설치 프로그램 서명
- [ ] 환경별 설정(dev/prod) 분리
- [ ] 자동 업데이트 정책 검토

---

## 5. UX

- [ ] 키보드 탭 순서
- [ ] 최소 창 크기와 DPI 스케일
- [ ] 다크 모드/고대비 정책(필요 시)

---

## 정리

WPF 품질은 컨트롤 개수가 아니라 **MVVM 규율 + 배포 체크리스트**를 끝까지 지키는 데서 나온다.
