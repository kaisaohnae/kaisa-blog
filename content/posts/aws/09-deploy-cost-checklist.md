# AWS 배포·비용 실무 체크리스트

> 요약: 계정부터 관측·백업·비용까지, 서비스를 프로덕션에 올리기 전에 볼 실무 체크리스트를 모은다.

---

## 1. 계정·권한

- [ ] 루트 MFA, 일상 작업은 IAM/SSO
- [ ] 프로덕션 권한과 배포 파이프라인 분리
- [ ] 시크릿은 Secrets Manager / SSM Parameter (평문 금지)

---

## 2. 네트워크·컴퓨트

- [ ] 앱/DB 프라이빗, ALB만 퍼블릭
- [ ] SG 최소 허용 (소스에 SG ID)
- [ ] 멀티 AZ 또는 최소 2 AZ
- [ ] 헬스체크·배포 롤링/블루그린 전략

---

## 3. 데이터

- [ ] RDS/스냅샷 백업 주기·보존
- [ ] S3 퍼블릭 차단, 버전관리(필요 시)
- [ ] 암호화(저장·전송)

---

## 4. 관측·운영

- [ ] 5xx·latency·디스크·빌링 알람
- [ ] 로그 보존·개인정보 마스킹
- [ ] 장애 시 연락 채널(SNS/Slack)
- [ ] IaC(Terraform/CDK/CloudFormation)로 재현

---

## 5. 비용

- [ ] 태그 필수 (`Project`, `Env`, `Owner`)
- [ ] 개발 자원 스케줄 중지
- [ ] NAT·ALB·퍼블릭 IPv4 비용 인지
- [ ] 예산 알람

---

## 정리

새 서비스보다 **체크리스트를 통과한 서비스**가 싸게, 오래 간다. AWS는 기능이 많아서가 아니라 경계를 명확히 해서 이긴다.
